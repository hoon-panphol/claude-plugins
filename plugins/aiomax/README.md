# AiOMax

เชื่อม Claude เข้ากับ [AiOMax](https://aiomax.panphol.com) — คลังข้อมูลหุ้นไทยและต่างประเทศที่จัดเก็บและตรวจสอบไว้แล้ว
Claude จะตอบจาก**ข้อมูลจริงที่ดึงมา** ไม่ใช่จากความจำของโมเดล

## ติดตั้ง

```
/plugin marketplace add hoon-panphol/claude-plugins
/plugin install aiomax@hoon-panphol
```

แล้วพิมพ์ `/mcp` เลือก `aiomax` → `Authenticate` เบราว์เซอร์จะเปิดหน้าล็อกอิน AiOMax
(เบอร์โทร, Google, Facebook, Apple หรือ LINE) ล็อกอินเสร็จแล้วกลับมาถามได้เลย

**ไม่ต้องกรอก token หรือ API key ใดๆ** — ใช้ OAuth 2.1 + PKCE เชื่อมต่อ ไม่มีความลับเก็บอยู่ในไฟล์ config
และไม่มีอะไรให้เผลอ commit ขึ้น git

## ใช้บน Claude Desktop หรือ claude.ai (แชทธรรมดา)

`/plugin` ใช้ได้เฉพาะ Claude Code — ถ้าใช้แชทปกติให้เพิ่มเป็น **custom connector** แทน
ได้เครื่องมือชุดเดียวกันทุกอย่าง

1. เปิด **Customize → Connectors** → **Add custom connector**
2. วาง URL นี้:
   ```
   https://aiomax.panphol.com/mcp
   ```
3. ช่อง OAuth Client ID / Client Secret ใน **Advanced settings** ให้ **เว้นว่างไว้** —
   ระบบจะค้นหาการตั้งค่า OAuth ของเซิร์ฟเวอร์เอง
4. กด **Add** แล้วล็อกอินสมาชิก AiOMax เมื่อหน้าต่างเด้งขึ้นมา
5. ในแชท กดปุ่ม **+** มุมล่างซ้าย → **Connectors** → เปิด AiOMax

ต้องใช้แพ็กเกจ Pro หรือ Max ขึ้นไป (Team/Enterprise ต้องให้ Owner เพิ่มที่
**Organization settings → Connectors**)

> การเชื่อมต่อวิ่งออกจากคลาวด์ของ Anthropic ไม่ใช่จากเครื่องคุณ — เซิร์ฟเวอร์จึงต้องเข้าถึงได้จากอินเทอร์เน็ตสาธารณะ
> (aiomax.panphol.com เข้าเงื่อนไขนี้อยู่แล้ว)

## ต้องเป็นสมาชิก

ต้องเป็นสมาชิก AiOMax ที่มีแพ็กเกจใช้งานอยู่ — บัญชี guest เชื่อมต่อไม่ได้
ทุกครั้งที่เรียกใช้เครื่องมือจะหักโควตารายเดือนของคุณตามปริมาณข้อมูลที่ส่งกลับ (`จำนวนตัวอักษร / 4`)
ถ้า auth ไม่ผ่านจะไม่ถูกหักโควตา สมัครหรือดูแพ็กเกจที่ https://aiomax.panphol.com

## ถามอะไรได้บ้าง

ไม่ต้องจำชื่อเครื่องมือ ถามเป็นภาษาไทยปกติได้เลย Claude จะเลือกเครื่องมือเอง

| อยากรู้เรื่อง | ลองถามแบบนี้ |
|---|---|
| ข่าว / งบ / บทวิเคราะห์รายตัว | `ข่าว PTT ล่าสุด` · `สรุปพื้นฐาน ADVANC` |
| ปันผล | `ประวัติปันผล SCC ย้อนหลัง` · `ปฏิทินปันผลเดือนหน้า` |
| สกรีนหุ้นด้วยตัวเลข | `หาหุ้น ROE > 15 PE < 12` · `หุ้นปันผลสูง D/E ต่ำ` |
| สกรีนเชิงเทคนิค | `คัดหุ้นเทคนิค RSI ต่ำ` · `หุ้นวอลุ่มพุ่ง` |
| เทียบหุ้น | `เทียบ ICHI กับ TACC` · `CPALL เทียบคู่แข่งในกลุ่ม` |
| ผู้ถือหุ้น / ผู้บริหารซื้อขาย | `ใครถือ DELTA บ้าง` · `ผู้บริหารซื้อขายหุ้นอะไรบ้าง` |
| กองทุน / ทอง / คริปโต / สินค้าโภคภัณฑ์ | `กองทุนไทยผลตอบแทนดี` · `ราคาทองวันนี้` |
| ภาพรวมเศรษฐกิจ | `ดอกเบี้ย กนง. ล่าสุด` · `ภาวะตลาดเดือนนี้` |
| จัดสัดส่วนพอร์ต | `จัดพอร์ต 1 ล้าน รับความเสี่ยงปานกลาง` |
| ทบทวนพอร์ตที่ถืออยู่ | แปะรายการหุ้นพร้อมต้นทุน แล้วถาม `วิเคราะห์พอร์ตหุ้น` |
| จำลองวิกฤต | `สเตรสพอร์ต` · `ถ้าตลาดพังจะเป็นยังไง` |

ใช้คู่กับปลั๊กอิน [portfolio-skills](../portfolio-skills) ได้ดี — AiOMax ให้ตัวเลขจริง
ส่วน portfolio-skills ให้กรอบการวิเคราะห์และรูปแบบผลลัพธ์

## ทางเลือก: ต่อด้วย Bearer token แทน OAuth

ถ้าต้องการเลี่ยงหน้าล็อกอิน (เช่นรันบนเซิร์ฟเวอร์ที่ไม่มีเบราว์เซอร์) เซิร์ฟเวอร์รับ Bearer token ด้วย
คัดลอก **AIO Max Token** (64 ตัวอักษร) จากหน้าโปรไฟล์ แล้วต่อเองโดยไม่ผ่านปลั๊กอินนี้

```
claude mcp add --transport http aiomax https://aiomax.panphol.com/mcp \
  --header "Authorization: Bearer YOUR_AIO_MAX_TOKEN"
```

Token นี้เท่ากับรหัสผ่าน — อย่าแปะลงไฟล์ที่ commit ขึ้น git และอย่าแชร์ให้ใคร

## ข้อจำกัด

ข้อมูลที่ได้เป็นมุมมองเชิงวิเคราะห์เพื่อการศึกษา **ไม่ใช่คำแนะนำการลงทุนเฉพาะบุคคล**
ทุก payload จะแนบ disclaimer มาด้วยเสมอ ตัดสินใจลงทุนจริงควรตรวจสอบข้อมูลอีกครั้ง
